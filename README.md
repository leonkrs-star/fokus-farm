# Fokus Farm

Tasks abhaken, Lernzeit tracken, Hof wachsen lassen.

**App öffnen:** https://leonkrs-star.github.io/fokus-farm/

- „I Showed Up“ 1–3 täglich mit Sofort-Belohnung
- Eigene Tasks (täglich oder einmalig) füllen die Gießkanne
- 45-Minuten-Fokus-Timer lässt alle Pflanzen eine Stufe wachsen
- Münzen gegen selbst festgelegte echte Belohnungen eintauschen

Der Spielstand wird im Browser des jeweiligen Geräts gespeichert (Backup unter *Tasks → Daten*).
Am iPhone: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
